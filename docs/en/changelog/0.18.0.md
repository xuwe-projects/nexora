# Nexora 0.18.0

Release date: 2026-07-29

This release remains in the `0.x` beta phase and does not enter the `1.x` stable channel. The
version uses the standard SemVer value `0.18.0`. This release standardizes CRUD table row identity
and selection as a strongly typed controlled model, and adds form-field components, official example
targets, and expanded component reference documentation.

## Added

- Added `nexora::desktop::LabeledControl`, `LabeledControlBuilder`, `Event`,
  `LabeledControlTarget`, `FieldValue`, `NumberFieldValue`, and `FieldValueParseError` for labels,
  descriptions, error text, declarative rules, typed field values, and async field events. Owner:
  [@Jixiangup](https://github.com/Jixiangup)
- Added typed field registration to `FormDialogState`. `FormDialog` now waits for the current async
  field task, runs declarative validation, and focuses the first invalid field before submit. Owner:
  [@Jixiangup](https://github.com/Jixiangup)
- Added `FormItem::error`, `FormItem::field`, and `FormItem::full_row` for reusable typed fields and
  full-width items in multi-column forms. Owner: [@Jixiangup](https://github.com/Jixiangup)
- Added controlled selection columns, row checkboxes, loaded-row bulk selection events, load-more
  state, and empty-state text configuration to `CrudTableDelegate`. Owner: [@Jixiangup](https://github.com/Jixiangup)
- Moved the minimal desktop and server examples into `crates/nexora/examples` as official
  `desktop_basic` and `server_basic` Cargo example targets, with README commands. Owner:
  [@Jixiangup](https://github.com/Jixiangup)
- Added the `refine-implementation-spec` Skill and synchronized it into the scaffold template.
  Owner: [@Jixiangup](https://github.com/Jixiangup)

## Changed

- `#[derive(nexora::CrudTableRow)]` now requires exactly one explicit `#[nexora(row_id)]` field, so
  the row type owns its strongly typed business ID. Owner: [@Jixiangup](https://github.com/Jixiangup)
- `CrudTableDelegate` validates loaded row ID uniqueness and manages rows through `replace_rows`,
  `append_rows`, and `update_rows`; `update_rows` only permits non-identity field edits or
  reordering existing rows. Owner: [@Jixiangup](https://github.com/Jixiangup)
- `TableHeaderCell` can now render arbitrary GPUI elements through `element`, which is also used by
  the selection-column header checkbox. Owner: [@Jixiangup](https://github.com/Jixiangup)
- Default Account user and role management filter areas now use `LabeledControl` for consistent
  labels, descriptions, and density. Owner: [@Jixiangup](https://github.com/Jixiangup)
- Form dialog height configuration is now `max_panel_height_ratio`. Short dialogs are no longer
  forced taller; long dialogs scroll only when they exceed the panel-relative cap. Owner:
  [@Jixiangup](https://github.com/Jixiangup)
- Repository rules, scaffold Skills, and generated-project constraints now emphasize component
  selection, Feature decomposition, server composition boundaries, and release verification. Owner:
  [@Jixiangup](https://github.com/Jixiangup)

## Fixed

## Compatibility and breaking changes

- Breaking change: `CrudTableRow` derive targets must declare exactly one `#[nexora(row_id)]` field.
  The old pattern of passing a row-ID closure to `CrudTableDelegate` is no longer kept.
- Breaking change: `CrudTableDelegate::rows_mut` is no longer the arbitrary mutation entry point.
  Replace full data with `replace_rows`, append pages with `append_rows`, and edit non-identity
  fields or reorder existing rows with `update_rows`.
- Breaking change: `FormDialog::panel_height_ratio` and `default_panel_height` are replaced by
  `max_panel_height_ratio`; the default behavior now fits short content and scrolls long content at
  the panel-relative cap.
- This release adds no database migrations, HTTP routes, or server configuration keys.

## Upgrade

1. Update the Nexora tag to `v0.18.0` and refresh the lockfile.
2. Add `#[nexora(row_id)]` to every `#[derive(nexora::CrudTableRow)]` struct. If the ID should not
   be visible, use `#[nexora(row_id, skip)]`.
3. Remove old `CrudTableDelegate::row_id(...)` calls and keep the business ID on the row type.
4. Replace `rows_mut()` with `replace_rows`, `append_rows`, or `update_rows`; do not add, remove, or
   change business IDs inside `update_rows`.
5. For row selection, use `CrudTableSelection::new(selected_ids, on_select_row,
   on_select_loaded_rows)`, update your business selected IDs in the event callbacks, then write the
   render snapshot back with `set_selected_ids`.
6. Replace `FormDialog::panel_height_ratio(...)` or `default_panel_height()` with
   `max_panel_height_ratio(...)`, or use the default.
7. Synchronize scaffold `.agents/skills`, especially the new `refine-implementation-spec` Skill and
   the updated GPUI, component-selection, Rust, and server rules.
8. To run the official examples, use `cargo run -p nexora --no-default-features --features
   desktop,derive --example desktop_basic` or `cargo run -p nexora --no-default-features --features
   server --example server_basic`.
