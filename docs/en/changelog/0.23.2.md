# Nexora 0.23.2

Release date: 2026-08-03

## Summary

This patch extends Settings-backed column-layout persistence to dynamic tables that must implement
gpui-component `TableDelegate` directly, without duplicating Nexora file I/O or merge logic.

Owner: [@Jixiangup](https://github.com/Jixiangup)

Related issues/PRs: none

## Added

- Added `PersistentDataTableDelegate` and `persistent_data_table_state_with`. They restore known
  column order and clamped widths, then save after native move or resize completion into the shared
  application `settings.json`. — Owner: [@Jixiangup](https://github.com/Jixiangup)

## Compatibility

- The 0.23.0/0.23.1 CRUD DataTable, Settings, multi-channel release, runtime config, feed, and
  schema 2 receipt contracts remain compatible.
- Native delegates keep owning their `perform_sort` behavior; use `CrudTableDelegate` for the
  generic backend-sort contract.

## Upgrading from 0.23.1

1. Update Nexora dependencies to `v0.23.2`.
2. Implement `PersistentDataTableDelegate` for tables that cannot use `CrudTableDelegate`, then
   call `persistent_data_table_state_with` with a stable `table_id`.
