# Nexora 0.30.2

Release date: 2026-08-07

## Summary

This is the second hotfix for the Windows Inno Setup 6 packaging path. `nexora build` no longer
passes values containing spaces, Unicode, or quotes through ISCC `/D...` command-line arguments.
It writes escaped preprocessor definitions directly into the generated `installer.iss` instead.
The Simplified Chinese messages are now pinned and bundled with the Nexora CLI rather than relying
on whether a particular Inno Setup installation includes contributed translations.

Owner: [@Jixiangup](https://github.com/Jixiangup)

Related issue/PR: none

## Fixed

- Fixed ISCC splitting Windows installer definitions containing spaces into extra script arguments
  and reporting `You may not specify more than one script filename`. Production compilation now
  passes only one `installer.iss` path to ISCC.
  — Owner: [@Jixiangup](https://github.com/Jixiangup)
- Fixed Simplified Chinese installer compilation failing because the official winget package for
  Inno Setup 6.7.3 does not include `Languages\Unofficial\ChineseSimplified.isl`. Nexora pins the
  messages file from the `is-6_7_3` source tag and retains its attribution and license.
  — Owner: [@Jixiangup](https://github.com/Jixiangup)

## Changed

- The Windows 2025 and Release workflows now compile a real Setup.exe through the production path,
  covering a Unicode application name, paths with spaces, a publisher containing quotes, and the
  x64 architecture expression in addition to checking the exact compiler version.
  — Owner: [@Jixiangup](https://github.com/Jixiangup)

## Compatibility

- The pinned tool remains Inno Setup 6.7.3; this release does not upgrade to Inno Setup 7.
- The `nexora.toml` schema, Windows install scope, artifact names, in-app update ZIP, signing
  boundaries, and publish protocol are unchanged.
- Projects that completed the 0.30.0 migration need no configuration changes. Windows configuration
  must still omit the removed `installer` and `install_scope` fields.

## Upgrading from 0.30.1

1. Update Nexora workspace dependencies to 0.30.2 or Git tag `v0.30.2`, then regenerate lockfiles.
2. Reinstall the CLI from `v0.30.2`; an existing official Inno Setup 6.7.3 installation does not
   need to be reinstalled.
3. Run `nexora build` again. The CLI regenerates `installer.iss` and the Simplified Chinese messages;
   manually deleting `.runtime/windows-build` is not required.
