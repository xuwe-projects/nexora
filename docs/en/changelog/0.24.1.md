# Nexora 0.24.1

## Fixes

- Windows NSIS packaging now accepts date-like or sequence-like large `build_number` values when generating `FileVersion`. Update manifests, artifact paths, and version comparisons still keep the full `build_number`; only the Windows resource version segment is mapped into the 16-bit range required by Windows. — Owner: [@openai](https://github.com/openai)
