# Nexora 0.17.1

Release date: 2026-07-28

This release remains in the `0.x` beta phase and does not enter the `1.x` stable channel. The
version uses the standard SemVer value `0.17.1`. This release fixes the default desktop Shell
sidebar brand area so the application name and subtitle no longer wrap character-by-character in a
narrow sidebar.

## Fixed

- Added width, overflow-hidden, and single-line truncation constraints to the default
  `SidebarHeader` brand row and text column. The application name and subtitle stay on one
  horizontal line and truncate when space is not enough. Owner: [@zhutao525](https://github.com/zhutao525)
- Added a Sidebar Shell source-contract regression test requiring the default brand Header to keep
  `w_full`, `flex_1`, `overflow_hidden`, `whitespace_nowrap`, and `truncate`, preventing future
  regressions to character-by-character wrapping. Owner: [@zhutao525](https://github.com/zhutao525)

## Changed

- Updated the root workspace version, internal workspace dependency constraints, CLI installation examples, and changelog indexes to `0.17.1`. Owner: [@zhutao525](https://github.com/zhutao525)

## Issues and PRs

- Issues: none. This release migrates the generic framework fix validated in iMES Portal's local
  refactor branch commit `51bb83d4`.
- PRs: none. Per the current release flow, this is committed, tagged, and released directly from the
  `codex/sidebar-brand-nowrap-v0.17.1` branch.

## Compatibility and breaking changes

- No breaking changes. Applications with a custom `SidebarHeader` are unaffected; applications using
  the default Header only receive the nowrap/truncate fix for the brand area.
- This release contains no database migrations and requires no extra data-upgrade step.

## Upgrade

1. Update the Nexora tag to `v0.17.1` and refresh the lockfile.
2. If the application uses the default Sidebar Header, no code change is needed to get single-line
   truncation for the brand name and subtitle.
3. If the application provides a custom `SidebarHeader`, decide inside that custom component whether
   to add `min_w_0`, `overflow_hidden`, `whitespace_nowrap`, and `truncate`.
