# Nexora 0.40.2

Release date: 2026-08-18

This release restores the native `gpui-component` title-bar proportions and aligns the visual size
of Shell toolbar icons, improving title-bar density on Windows and macOS.

## Fixed

- Stop forcing the official `TitleBar` from its 34px default to 44px. Window controls and macOS
  traffic lights remain entirely managed by the upstream layout.

  — Owner: [@Jixiangup](https://github.com/Jixiangup)
  — Related issue/PR: none

- Use 16px visible icons for back, forward, reload, open-page, and standard `ShellToolbarAction`
  buttons so they match Feature tab icons. Hit targets remain 32×32px, with hover, disabled,
  loading, and tooltip behavior preserved. Sidebar icons remain at 20px.

  — Owner: [@Jixiangup](https://github.com/Jixiangup)
  — Related issue/PR: none

- Add workspace-layout and Shell-toolbar regression coverage for the upstream title-bar height,
  16px toolbar icons, and 32×32px hit targets.

  — Owner: [@Jixiangup](https://github.com/Jixiangup)
  — Related issue/PR: none

## Compatibility and breaking changes

- This is a backward-compatible patch for `v0.40.1`. It adds or removes no public configuration,
  routes, database structures, or HTTP APIs.
- No custom title-bar-height API or private `gpui-component` fork is introduced.
- There are no breaking changes and no manual data migration or rollback steps.

## Upgrading from 0.40.1

1. Update every Nexora Git dependency tag from `v0.40.1` to `v0.40.2`.
2. Run `cargo update` and confirm that Nexora workspace packages in `Cargo.lock` resolve to
   `v0.40.2`.
3. Rebuild the desktop application. Applications using the standard `WorkspaceLayout` and
   `ShellToolbarAction` automatically adopt the new proportions.

This release does not change scaffold Skills, generated-project constraints, or custom macro rules,
so downstream projects do not need to synchronize `.agents/skills`.
