# Nexora 0.36.0

Release date: 2026-08-14

## Summary

This release turns the desktop Shell, global search, theming, and standard CRUD lists into extensible
public contracts. The Sidebar now reaches the top of the window while the right workspace owns a
separate title bar, compact tab bar, and page content. The tab prefix always contains back, forward,
and reload controls, with reload capability declared by the active Feature. Applications can register
theme presets, search providers, and toolbar actions, while standard master-data lists share typed
pagination, filters, sorting, selection, and row actions through `CrudQuery`, `CrudListState`, and
`CrudPanel`.

Owner: [@Jixiangup](https://github.com/Jixiangup)

Related Issue/PR: none

## Added

- Added the `CrudQuery` derive and query metadata for page-size limits, filter controls and triggers,
  validation, defaults, and optional server sort enums. Request DTOs remain application-owned and
  Nexora does not rewrite their serialized wire format. — Owner: [@Jixiangup](https://github.com/Jixiangup)
- Added `CrudListState<Row, Query>` and the new `CrudPanel<Row, Query>` for initial load, reload,
  pagination, load-more, filtering, server sorting, loaded-row selection, delegated row actions, and
  errors. `create_with_app` resolves authentication and business context when each request runs.
  — Owner: [@Jixiangup](https://github.com/Jixiangup)
- Added global search providers, modes, sections, asynchronous requests, history resolution, and
  actions. Search history is partitioned by account and can be disabled or cleared.
  — Owner: [@Jixiangup](https://github.com/Jixiangup)
- Added `ShellToolbarAction` and the Feature reload lifecycle. Back, forward, and reload are always
  present in the tab prefix; pages without reload capability disable the control without changing
  layout. — Owner: [@Jixiangup](https://github.com/Jixiangup)
- Added application theme-preset registration and default selection. Each preset provides a light and
  dark theme, and Settings enumerates the runtime catalog. — Owner: [@Jixiangup](https://github.com/Jixiangup)
- Added `TableSwitchCell` for controlled boolean table actions with consistent loading and disabled
  behavior. — Owner: [@Jixiangup](https://github.com/Jixiangup)

## Changed

- Rebuilt the Shell so the Sidebar reaches the window top and the right workspace separately lays out
  the global title bar, fixed-height tab bar, and content. The global-search trigger and Feature icon
  tab prefixes now follow the checked-in prototype. — Owner: [@Jixiangup](https://github.com/Jixiangup)
- Advanced `workspace.toml` to schema 3 for Sidebar collapse state and account-partitioned search
  history. Historical theme ID `xuwe` migrates to `nexora`; unknown presets and color modes fall back
  safely. — Owner: [@Jixiangup](https://github.com/Jixiangup)
- Sortable `CrudTableRow` columns now require explicit server-enum mappings, preventing UI column keys
  from leaking into API requests. — Owner: [@Jixiangup](https://github.com/Jixiangup)
- Migrated default Account user and role pages to the new Shell, reload, and official form-component
  boundaries; examples, scaffolds, component-selection rules, and bilingual desktop docs follow the
  same contract. — Owner: [@Jixiangup](https://github.com/Jixiangup)
- Pinned GPUI to `cc053a4a6fa2fd0e8793201ed9099466af1be0b1` and `gpui-component` plus assets
  to `55b6bb88905d8e76cd23d9e3ebea3151dcdb84a0`; scaffolds emit the same combination.
  — Owner: [@Jixiangup](https://github.com/Jixiangup)

## Fixed

- Fixed the tab-bar root consuming all remaining height and leaving a large blank region above pages.
- Fixed the Sidebar being pushed below the right-side title bar instead of reaching the window top.
- Fixed reload disappearing from the tab prefix on unsupported pages; it now remains visible and
  accurately reflects the active Feature state. — Owner: [@Jixiangup](https://github.com/Jixiangup)

## Compatibility and breaking changes

- Removed legacy `Card`, `FormItem`, `LabeledControl`, `CrudPanelToolbar`, `PanelHeaderAction`, and its
  installer. Use official `gpui-component` controls and `ShellToolbarAction` for application actions.
- `CrudPanel` is now `CrudPanel<Row, Query>` and receives its filters, sorting, selection, and actions
  through `CrudListState` and delegates. Complex workbenches should compose official controls directly.
- Sortable `CrudTableRow` fields without a server-sort mapping fail to compile. `CrudQuery` requires one
  pagination field, and its sort field must be `Option<Sort>`.
- `FormDialog` no longer hosts the legacy field wrappers; compose `gpui_component::form::field()` directly.
- Schema 3 stores Sidebar and search-history preferences. v0.35.0 ignores these fields on rollback;
  database schemas, HTTP APIs, and updater protocols are unaffected.

## Upgrade from 0.35.0

1. Update all Nexora workspace dependencies and the CLI to `v0.36.0`, then regenerate `Cargo.lock`.
2. Compile the application against a local Nexora path while migrating, and switch to this release tag
   only after application verification.
3. Replace `PanelHeaderAction` with `ShellToolbarAction`. Implement `reload_availability` and `reload`
   for remote-data Features; static pages keep reload disabled.
4. Replace removed UI wrappers with official `field()`, `GroupBox`, `Button`, `Input`, `Select`,
   `DataTable`, and `Switch` components. Keep complex workbench layouts private to their Feature.
5. Derive `CrudQuery` for standard single-list requests, add explicit server-sort mappings, and adopt
   `CrudListState` plus the new `CrudPanel` without changing existing HTTP filters or wire fields.
6. Register branded light/dark themes through `ApplicationOptions::theme_preset`, optionally selecting
   the default with `default_theme_preset`.
7. Visually verify top-aligned Sidebar, search trigger, compact tabs, Feature icon prefixes,
   back/forward/reload, theme switching, standard list behavior, and complex workbench layouts.
