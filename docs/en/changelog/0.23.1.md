# Nexora 0.23.1

Release date: 2026-08-03

## Summary

This patch adds a gpui-component `TableState` configuration hook to the persistent CRUD DataTable
constructor introduced in 0.23.0, so adopting layout and backend-sort persistence does not change
an application's existing selection or interaction behavior.

Owner: [@Jixiangup](https://github.com/Jixiangup)

Related issues/PRs: none

## Added

- Added `nexora::desktop::persistent_crud_table_state_with`. Its `configure` callback preserves
  existing builder choices such as `row_selectable`, `col_selectable`, `sortable`, column movement,
  and column resizing. — Owner: [@Jixiangup](https://github.com/Jixiangup)

## Compatibility

- `persistent_crud_table_state` keeps its existing signature and behavior and delegates to the new
  entry point with the default `TableState` configuration.
- All 0.23.0 Settings migration, table persistence, multi-channel release, runtime configuration,
  feed, and schema 2 receipt contracts remain unchanged.

## Upgrading from 0.23.0

1. Update all Nexora dependencies to `v0.23.1`.
2. Persistent tables that previously required `.row_selectable(false)` or other `TableState`
   builder options should call `persistent_crud_table_state_with` and retain those options in the
   `configure` callback.
