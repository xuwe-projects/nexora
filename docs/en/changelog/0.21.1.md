# Nexora 0.21.1

Release date: 2026-08-03

## Summary

This patch completes the public updater sidecar facade so applications and their standalone
sidecars depend only on `nexora::desktop`. It also turns the updater documentation into an
executable first-time setup, configuration, signing, publishing, and production-hardening guide.

Owner: [@Jixiangup](https://github.com/Jixiangup)

Related issue/PR: none.

## Fixed

- Publicly re-exported `run_sidecar_from_env_args` and `report_health_from_env_args` from
  `nexora::desktop`, removing the need for applications to depend on the internal updater crate.
  — Owner: [@Jixiangup](https://github.com/Jixiangup)
- Migrated `examples/updater-macos` to the public sidecar entry point, removed its direct updater
  dependency, and added a facade regression test. — Owner: [@Jixiangup](https://github.com/Jixiangup)

## Documentation

- Documented CLI and tool installation, doctor/fix, first project/build/DMG install/publish/update,
  and the distinct responsibilities of build, publish, ZIP, DMG, manifest, and sidecar.
  — Owner: [@Jixiangup](https://github.com/Jixiangup)
- Documented every updater/build/publish configuration field, exact defaults, strict signing-key
  precedence, credential boundaries, Ed25519 rotation order, and the full verification chain.
  — Owner: [@Jixiangup](https://github.com/Jixiangup)
- Clarified that HTTP and ad-hoc signing are local-only; production requires HTTPS, Developer ID,
  notarization, and an expected Apple Team ID. — Owner: [@Jixiangup](https://github.com/Jixiangup)

## Compatibility

There are no breaking changes and no manual configuration or data migration. Existing sidecars
that directly depend on the updater crate continue to work, but should migrate to the public facade.

## Upgrade from 0.21.0

1. Move all Nexora dependencies to `v0.21.1` and regenerate the lockfile.
2. Replace `updater::run_sidecar_from_env_args()` with
   `nexora::desktop::run_sidecar_from_env_args()` and remove the internal updater dependency.
3. Re-run `nexora doctor`, `nexora build --app <key>`, and the publish dry run.

No scaffold Skill or macro rule changed in this release.
