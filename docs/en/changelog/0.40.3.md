# Nexora 0.40.3

Release date: 2026-08-18

This release fixes the desktop Shell title-bar global-search trigger so it opens reliably with the
mouse. The double-Shift shortcut, search contents, and dragging from empty title-bar space remain
unchanged.

## Fixed

- Continue using the official `gpui-component::Button` and `Dialog`, while stopping the button's
  left-mouse-down event from propagating into the official `TitleBar` window-drag handler. Mouse
  clicks and double Shift now enter the same `open_search` flow.

  — Owner: [@Jixiangup](https://github.com/Jixiangup)
  — Related issue/PR: none

- Add a Shell regression assertion requiring the global-search button's own interaction region to
  remain isolated from title-bar dragging, rather than checking only that an `.on_click` handler is
  present.

  — Owner: [@Jixiangup](https://github.com/Jixiangup)
  — Related issue/PR: none

- Remove the Sidebar source-structure test's implicit dependency on `LF` line endings, so the same
  assertion precisely locates its target in Windows `CRLF` worktrees. Sidebar runtime behavior is
  unchanged.

  — Owner: [@Jixiangup](https://github.com/Jixiangup)
  — Related issue/PR: none

## Compatibility and breaking changes

- This is a backward-compatible patch for `v0.40.2`. It adds or removes no public APIs,
  configuration, routes, database structures, or HTTP APIs.
- The release metadata version in `docs/public/openapi.yaml` is synchronized to `0.40.3`; the API
  contract itself is unchanged.
- Empty title-bar space remains draggable. Registered global-search shortcuts, search providers,
  and search-history behavior are unchanged.
- There are no breaking changes and no manual data migration or rollback steps.

## Upgrading from 0.40.2

1. Update every Nexora Git dependency tag from `v0.40.2` to `v0.40.3`.
2. Run `cargo update` and confirm that Nexora workspace packages in `Cargo.lock` resolve to
   `v0.40.3`.
3. Rebuild the desktop application and verify that both clicking the title-bar global-search
   trigger and double Shift open the search window.

This release does not change scaffold Skills, generated-project constraints, or custom macro rules,
so downstream projects do not need to synchronize `.agents/skills`.
