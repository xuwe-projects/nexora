# Nexora 0.21.3

Release date: 2026-08-03

## Summary

This patch fixes the Sidebar Footer “Check for Updates” item failing to open its dialog because the
action re-entered the active window during the same window event. It also adds a cross-platform
default shortcut and displays it in the menu.

Owner: [@Jixiangup](https://github.com/Jixiangup)

Related issue/PR: none.

## Fixed

- The `CheckForUpdates` action now defers its active-window update until the current GPUI window
  event completes, preventing the Footer menu action from silently skipping the updater dialog due
  to window re-entry. — Owner: [@Jixiangup](https://github.com/Jixiangup)
- `install_updater` now registers `Cmd+Shift+U` on macOS and `Ctrl+Shift+U` on Windows/Linux. The
  Sidebar Footer menu displays the current platform shortcut. — Owner:
  [@Jixiangup](https://github.com/Jixiangup)
- Added regression coverage for the menu action, shortcut binding, and deferred window update. —
  Owner: [@Jixiangup](https://github.com/Jixiangup)

## Documentation

- Documented that the Sidebar Footer, native macOS menu, and shortcut dispatch the same
  `CheckForUpdates` action. — Owner: [@Jixiangup](https://github.com/Jixiangup)

## Compatibility

There are no breaking changes and no manual migration is required. Desktop applications that call
`nexora::desktop::install_updater` only need to upgrade all Nexora dependencies and rebuild to gain
the fixed Footer entry and default shortcut. Applications without an installed updater still expose
no check-for-updates entry.

## Upgrade from 0.21.2

1. Move every Nexora dependency to `v0.21.3` and regenerate the lockfile.
2. Rebuild the desktop application.
3. Click “Check for Updates” in the Sidebar Footer and verify both the displayed shortcut and its
   keyboard behavior.

This release does not change scaffold Skills, macro rules, or generated-project constraints, so
downstream `.agents/skills` copies do not need synchronization.

## Validation

- `cargo fmt --all --check`
- `cargo test --workspace --all-targets`
- `cargo clippy --workspace --all-targets --all-features -- -D warnings`
- `cargo run -p nexora -- lint --workspace . --deny-warnings`
- `bash scripts/check-scaffold-consumer.sh`
- `cd docs && bun install --frozen-lockfile && bun run build`

GPUI test windows are not backed by real native macOS windows, so automated tests cannot render the
updater dialog directly. A packaged-application click and shortcut smoke test remains recommended
after release.
