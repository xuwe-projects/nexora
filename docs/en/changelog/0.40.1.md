# Nexora 0.40.1

## Fixes

- `@Jixiangup`: export `CreateServiceAccountIdentity` from `nexora::account` and
  `nexora::server`, allowing host applications to call the
  `Account::create_or_reuse_service_account` API introduced in 0.40.0.
- Add a public-facade compilation test so a public service-account method cannot regress to an
  unreachable input type.

## Compatibility

- This is a backward-compatible 0.40.0 patch without database migrations, configuration changes,
  or behavior changes.
- Projects using the service-account host API should upgrade directly to `v0.40.1`; other 0.40.0
  consumers require no source changes.

## Verification

- `cargo fmt --all -- --check`
- `cargo check --workspace --all-targets`
- `cargo test -p nexora --features desktop,server,derive`
- `cargo clippy --workspace --all-targets --all-features -- -D warnings`
- `cargo run -p cli -- lint --workspace --deny-warnings`
