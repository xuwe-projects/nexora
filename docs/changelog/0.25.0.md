# Nexora 0.25.0

发布日期：2026-08-04

## 摘要

本版本为桌面 Account 登录增加安全的会话保持、静默恢复和自动续期能力，并恢复构建产物
SHA-256 旁车与本机时区构建号。macOS 使用 Keychain，Windows 使用 Credential Manager；
Linux 不持久化令牌。退出登录会立即清理内存会话，并尽力删除凭据和撤销 refresh token。

处理人：[@Jixiangup](https://github.com/Jixiangup)

关联 Issue/PR：无

## Added

- 桌面 Account 运行时支持把 refresh token、OIDC subject 和最小 profile 保存到 macOS
  Keychain 或 Windows Credential Manager，并在启动时静默恢复后重新执行 Account `/me`
  业务门禁。— 处理人：[@Jixiangup](https://github.com/Jixiangup)
- Access Token 会在到期前后台续期；临时网络或 Provider 错误使用有限退避，`invalid_grant`、
  subject 不一致和业务账号禁用等终态会禁止恢复并清理本地凭据。— 处理人：
  [@Jixiangup](https://github.com/Jixiangup)
- 默认登录门禁增加“保持登录状态”、恢复重试和使用其他账号登录入口；自定义登录页可通过
  `login_snapshot`、`set_remember_login`、`retry_recovery` 和 `login_with_other_account` 接入相同
  能力。— 处理人：[@Jixiangup](https://github.com/Jixiangup)
- OIDC 客户端新增类型化 `prompt=select_account`、refresh token 撤销以及 Provider 未声明撤销
  端点时的非致命结果。— 处理人：[@Jixiangup](https://github.com/Jixiangup)

## Changed

- 桌面 Account 配置会确保 scope 包含 `offline_access`；Linux 明确禁用“保持登录状态”，不会
  接入 Secret Service，也不会把 token 写入普通文件。— 处理人：
  [@Jixiangup](https://github.com/Jixiangup)
- `nexora build` 为 macOS 与 Windows 的最终产物生成标准 `<artifact>.sha256` 文件；publish
  上传并匿名校验旁车，同时仍以签名 manifest 保护更新协议。— 处理人：
  [@Jixiangup](https://github.com/Jixiangup)
- `${BUILD_DATETIME}` 使用构建机器本机时区的 24 小时制 `yyMMddHHmmss`，并继续保证相对上一
  构建号严格递增。— 处理人：[@Jixiangup](https://github.com/Jixiangup)

## Fixed

- Windows 安装器检查路径与普通 build 路径统一使用本机固定偏移时间，避免多通道发布代码与
  动态构建号函数发生类型不匹配。— 处理人：[@Jixiangup](https://github.com/Jixiangup)

## 兼容性与破坏性变更

没有破坏性变更，也不需要数据库迁移。已有单通道与多通道发布配置继续可用。未选择“保持登录
状态”的应用维持原有进程内登录行为；Linux 行为也保持为不持久化令牌。

安全存储失败不会中断当前进程登录，但下次启动不能静默恢复。普通退出不会执行 Provider 全局
登出或清除浏览器 Cookie，因此浏览器 SSO 会话仍可能存在。

## 从 0.24.2 升级

1. 将全部 Nexora 依赖和 CLI 安装 tag 统一更新到 `v0.25.0`，并重新生成 lockfile。
2. 使用默认登录门禁的应用无需改代码；自定义 `LoginFeature` 可按需读取新增的无敏感快照字段
   并接入保持登录、恢复重试和账号切换动作。
3. 确认 OIDC Provider 允许 `offline_access` 和 refresh token；如 Provider 提供
   `revocation_endpoint`，退出会尽力撤销 refresh token。
4. 重新执行 `nexora build` 和 `nexora publish --dry-run`，确认每个最终产物对应的
   `.sha256` 旁车、匿名 URL 和签名 `latest.json` 均通过验证。
5. 下游项目同步 `.agents/skills/develop-nexora-updater` 及其 `updater-protocol.md`，以采用本机
   构建号和 SHA-256 旁车的最新 build/publish 约束。本版本未修改自定义宏规则。
