# Nexora 0.21.1

发布日期：2026-08-03

## 摘要

本补丁补齐 updater sidecar 的公共 facade，让应用与独立 sidecar 都只依赖
`nexora::desktop`，并把首次准备、完整配置字段、密钥优先级、验证链路和生产 macOS 签名流程
整理为可直接执行的文档。

处理人：[@Jixiangup](https://github.com/Jixiangup)

关联 Issue/PR：无

## Fixed

- 从 `nexora::desktop` 公开 re-export `run_sidecar_from_env_args` 与
  `report_health_from_env_args`；应用无需直接依赖内部 `updater` crate。
  — 处理人：[@Jixiangup](https://github.com/Jixiangup)
- `examples/updater-macos` 的 sidecar 改用公共入口，并移除对内部 updater crate 的直接依赖；
  新增 facade 回归测试。— 处理人：[@Jixiangup](https://github.com/Jixiangup)

## Documentation

- 完整记录 CLI 安装、`doctor`/`doctor --fix`、Rust/Xcode/cargo-bundle/create-dmg 前置条件、首次
  项目/构建/DMG 安装/发布/升级，以及 build、publish、`.app.zip`、DMG、`latest.json` 和
  sidecar 的职责。— 处理人：[@Jixiangup](https://github.com/Jixiangup)
- 为所有 `nexora.toml` updater/build/publish 字段补充必填性、来源、默认值、示例、秘密属性和
  错误行为，并明确私钥文件不回退、三类凭据边界、Ed25519 轮换顺序和完整签名验证链。
  — 处理人：[@Jixiangup](https://github.com/Jixiangup)
- 明确 HTTP/ad-hoc 仅用于本地验证，生产必须使用 HTTPS、Developer ID、notarization 和预期
  Apple Team ID。— 处理人：[@Jixiangup](https://github.com/Jixiangup)

## 兼容性与破坏性变更

没有破坏性变更，也不需要配置或数据迁移。原来直接依赖 `updater` crate 的 sidecar 可继续工作，
但应改为公共 `nexora::desktop` 入口。

## 从 0.21.0 升级

1. 将全部 Nexora 依赖统一更新到 `v0.21.1` 并重新生成 lockfile。
2. 把 sidecar 调用从 `updater::run_sidecar_from_env_args()` 改为
   `nexora::desktop::run_sidecar_from_env_args()`，删除应用对内部 updater crate 的依赖。
3. 重新运行 `nexora doctor`、`nexora build --app <key>` 和发布 dry-run。

本版本没有修改脚手架 Skill 或宏规则，下游无需同步额外 Skill 文件。
