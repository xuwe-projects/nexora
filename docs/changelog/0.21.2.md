# Nexora 0.21.2

发布日期：2026-08-03

## 摘要

本补丁修复 macOS updater 以健康确认参数重启应用时，默认配置加载器把内部 flag 误判为 TOML
路径并导致新版本退出、sidecar 超时回滚的问题。

处理人：[@Jixiangup](https://github.com/Jixiangup)

关联 Issue/PR：无

## Fixed

- `nexora::config::initialize(None)` 识别并忽略作为首参出现的
  `--nexora-updater-health-session` / `--nexora-updater-health-file`，继续按应用默认路径加载配置；
  显式路径与普通位置参数行为不变。— 处理人：[@Jixiangup](https://github.com/Jixiangup)
- 新增配置参数选择回归测试，覆盖 updater 健康参数与普通配置路径。— 处理人：
  [@Jixiangup](https://github.com/Jixiangup)

## Documentation

- 补充 `install_updater` 的 sidecar 健康启动与配置加载兼容说明。— 处理人：
  [@Jixiangup](https://github.com/Jixiangup)

## 兼容性与破坏性变更

没有破坏性变更。依赖 `initialize(None)` 的桌面应用无需改代码；升级并重新构建后即可让 sidecar
启动参数与默认配置加载共存。

## 从 0.21.1 升级

1. 将全部 Nexora 依赖统一更新到 `v0.21.2` 并重新生成 lockfile。
2. 重新构建 `.app.zip`、DMG 和 sidecar；旧客户端可以安装由新版本构建的应用负载。
3. 执行真实替换、健康确认和失败回滚验证。
