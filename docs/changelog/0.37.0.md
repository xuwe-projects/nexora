# Nexora 0.37.0

发布日期：2026-08-14

## 摘要

本版本继续收敛桌面 Shell、标准 CRUD 表格与 Account 用户目录的公共契约。Shell 使用统一的
236px/80px Sidebar 布局轴和过渡动画，收起后的嵌套导航可通过官方菜单继续访问；全局搜索改由
稳定 Action 与真实 GPUI 按键绑定驱动。标准表格现在显式声明状态列并由 lint 校验字段边界，
分页始终提供数字页码。Account 用户目录新增关键词、状态和账号类型筛选，并由默认用户页面与
全局搜索共同复用。

处理人：[@Jixiangup](https://github.com/Jixiangup)

关联 Issue/PR：无

## Added

- 新增 `global_search::OpenGlobalSearch` Action 与 `ShortcutHint`，Shell 只在应用注册真实绑定时
  展示完整按键序列，并允许下游按平台选择快捷键。— 处理人：[@Jixiangup](https://github.com/Jixiangup)
- 新增 `ShellToolbarOptions`、`ShellToolbarAction::icon_button` 与带选项的安装入口，统一 Shell
  工具动作的点击区域、图标尺度和右侧间距。— 处理人：[@Jixiangup](https://github.com/Jixiangup)
- Account 新增 `UserListQuery`、`AccountSession::list_users_filtered` 和服务端筛选实现，支持按
  用户 ID、登录名、邮箱、姓名、状态与账号类型查询。— 处理人：[@Jixiangup](https://github.com/Jixiangup)
- `CrudTableRow` 新增 `column(status, render = ..., text = ...)` 契约及编译期诊断；
  `nexora lint` 同步检查状态列、合并业务值、布尔开关和语义 Tag 用法。
  — 处理人：[@Jixiangup](https://github.com/Jixiangup)

## 兼容性与破坏性变更

- `CrudTableRow` 的业务状态列必须显式声明 `status`、专用 `render` 与纯文本 `text`；旧项目若
  把头像、姓名、用户名、ID 等多个值合并在一个数据单元格，或用通用渲染掩盖状态语义，新的
  lint 会拒绝该写法。布尔状态必须使用 `TableSwitchCell`，其他状态必须使用填充语义 `Tag`。
- 上述约束属于 0.x 阶段的公开宏与脚手架规则变更，因此版本递增 MINOR。宏仍保持现有字段和
  HTTP wire，不自动改写业务 DTO。
- `GET /users` 只增加可选的 `keyword`、`status` 与 `user_type` 查询参数；原有 `page`、
  `page_size` 和无筛选调用继续兼容。没有修改 HTTP 路径、响应结构或权限键。
- `install_shell_toolbar_actions` 和 `AccountSession::list_users` 继续保留；新布局选项和筛选入口
  均为增量 API。没有新增 SQLx migration、PostgreSQL schema 或更新器协议变化。

## 从 0.36.0 升级

1. 把全部 Nexora workspace 依赖和 CLI 切换到 Git tag `v0.37.0`，删除临时本地 path/patch，
   然后重新生成 `Cargo.lock`；不要继续依赖发布工作区的本地路径。
2. 同步本版本的 `.agents/skills/desktop-ui-component-selection`、`.agents/skills/gpui-component`
   与脚手架 `AGENTS.md` 规则，再运行 `nexora lint --deny-warnings`。
3. 为每个业务状态列补充 `column(status, render = ..., text = ...)`，把合并业务值拆到独立列；
   布尔状态使用 `TableSwitchCell`，其他状态按语义选择填充 `Tag`。
4. 需要用户目录筛选时改用 `UserListQuery` 或 `AccountSession::list_users_filtered`；原有
   `list_users(page, page_size)` 无需修改。
5. 为 `OpenGlobalSearch` 注册应用自己的 GPUI 按键绑定；没有绑定时 Shell 会自然隐藏快捷键提示。
6. 涉及自定义 `CrudTableRow` 宏用法的应用应检查 `cargo expand`，与手写等价实现对比，并运行
   `cargo bench`、`cargo bloat`；若性能或体积未达标，再用 `cargo asm` 定位并完成分析闭环。
7. 人工核对 Sidebar 展开/收起与嵌套菜单、搜索快捷键、工具动作、用户筛选、状态列和单页/多页
   分页表现。
