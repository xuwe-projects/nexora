# Nexora 0.41.2

发布日期：2026-08-20

本版本修复标准 CRUD 表格滚动到尚未加载的数据范围时，GPUI 因同一个
`TableState` 被重入更新而导致 Windows 桌面应用闪退的问题。

## 修复

- `CrudListState` 现在把可见行范围预加载延迟到当前 DataTable 回调退出后执行，
  避免在 `TableState` 仍持有可变租借时同步请求下一页并回写稀疏行状态。

  — 处理人：[@Jixiangup](https://github.com/Jixiangup)
  — 关联 Issue/PR：[xuwe-projects/imes#299](https://github.com/xuwe-projects/imes/issues/299)

- 增加确定性 GPUI 回归测试，直接模拟表格持有状态租借时触发可见区变化，验证
  下一页仍会被预加载且不会再触发 double-lease panic。

  — 处理人：[@Jixiangup](https://github.com/Jixiangup)
  — 关联 Issue/PR：[xuwe-projects/imes#299](https://github.com/xuwe-projects/imes/issues/299)

## 兼容性与破坏性变更

- 这是 `v0.41.1` 的向后兼容补丁，不新增或删除公开 API、可见组件、HTTP 路由、
  数据库结构、Updater manifest schema、签名协议或发布对象布局。
- 分页、页缓存、稀疏 Skeleton 和可见范围预加载行为保持不变；仅调整预加载动作的
  调度时机。
- `docs/public/openapi.yaml` 只同步发布元数据版本到 `0.41.2`，API 契约未变。
- 无破坏性变更，无需手工数据迁移。

## 从 0.41.1 升级

1. 将所有 Nexora Git 依赖与 CLI 安装 tag 从 `v0.41.1` 更新为 `v0.41.2`。
2. 运行 `cargo update`，确认 `Cargo.lock` 中 Nexora workspace package 指向
   `v0.41.2` 对应提交。
3. 重新构建桌面应用，并回归滚动跨页的客户、供应商等标准 CRUD 表格。
4. 本版本没有 Skill 或协议变化，无需同步 `.agents/skills`。
