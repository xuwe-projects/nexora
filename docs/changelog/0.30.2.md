# Nexora 0.30.2

发布日期：2026-08-07

## 摘要

这是 Windows Inno Setup 6 安装包生成链路的第二个热修复版本。`nexora build` 不再通过
ISCC `/D...` 命令行参数传递包含空格、中文或双引号的构建值，而是把经过转义的预处理定义
写入生成的 `installer.iss`。简体中文消息文件也固定随 Nexora CLI 提供，不再依赖不同 Inno
Setup 安装方式是否附带非官方翻译。

处理人：[@Jixiangup](https://github.com/Jixiangup)

关联 Issue/PR：无

## Fixed

- 修复 ISCC 把含空格的 Windows 安装器定义拆成额外脚本参数，并报
  `You may not specify more than one script filename` 的问题。正式编译现在只向 ISCC 传入一个
  `installer.iss` 路径。— 处理人：[@Jixiangup](https://github.com/Jixiangup)
- 修复官方 winget 安装的 Inno Setup 6.7.3 不包含
  `Languages\Unofficial\ChineseSimplified.isl`，导致简体中文安装包编译中止的问题。Nexora
  固定内嵌 `is-6_7_3` 源码 tag 中的中文消息文件，并保留原始署名与许可证。
  — 处理人：[@Jixiangup](https://github.com/Jixiangup)

## Changed

- Windows 2025 与 Release 工作流现在不仅验证精确编译器版本，还使用生产生成路径实际编译
  Setup.exe，并覆盖中文应用名、带空格的目录、带双引号的发布者以及 x64 架构表达式。
  — 处理人：[@Jixiangup](https://github.com/Jixiangup)

## 兼容性

- 固定工具版本仍为 Inno Setup 6.7.3；本版本不升级到 Inno Setup 7。
- `nexora.toml` schema、Windows 安装范围、产物名称、应用内更新 ZIP、签名边界和发布协议均
  不变。
- 已完成 0.30.0 迁移的项目无需修改配置；Windows 配置仍不得包含已删除的 `installer` 与
  `install_scope` 字段。

## 从 0.30.1 升级

1. 把 Nexora workspace 依赖更新为 0.30.2 或 Git tag `v0.30.2`，重新生成 lockfile。
2. 使用 `v0.30.2` 重新安装 CLI；无需重新安装现有的官方 Inno Setup 6.7.3。
3. 重新执行 `nexora build`。CLI 会重新生成 `installer.iss` 与简体中文消息文件，无需手工清理
   `.runtime/windows-build`。

## 验证

发布前执行并通过：

- `cargo fmt --all --check`
- `cargo check --workspace --locked`
- `cargo test --workspace --all-targets --locked`
- `cargo clippy --workspace --all-targets --all-features --locked -- -D warnings`
- `cargo run -p cli --locked -- lint --workspace . --deny-warnings`
- `bash scripts/check-scaffold-consumer.sh`
- `cd docs && bun install --frozen-lockfile && bun run build`
- `cargo build -p cli --release --locked`，并确认产物输出 `nexora 0.30.2`
- Windows 2025 runner 通过 winget 安装官方 Inno Setup 6.7.3，生产版本探测读取到 `6.7.3`，
  并在包含中文和空格的路径中真实生成非空 Setup.exe

本热修复不把安装向导人工交互、卸载、原地升级或 sidecar 更新声明为新增验证范围。
