# Nexora 0.23.1

发布日期：2026-08-03

## 摘要

本补丁为 0.23.0 新增的持久化 CRUD DataTable 构造器补齐 gpui-component `TableState`
选项配置入口，确保下游接入列布局与后台排序持久化时不会改变既有选择和交互行为。

处理人：[@Jixiangup](https://github.com/Jixiangup)

关联 Issue/PR：无

## Added

- 新增 `nexora::desktop::persistent_crud_table_state_with`；业务通过 `configure` 回调保留
  `row_selectable`、`col_selectable`、`sortable`、列移动和列宽调整等原有 builder 配置。
  — 处理人：[@Jixiangup](https://github.com/Jixiangup)

## Compatibility

- `persistent_crud_table_state` 的签名与行为保持兼容，并委托新入口使用默认 `TableState` 配置。
- 0.23.0 的 Settings 路径、迁移、表格持久化、多通道 release、runtime config、feed 与
  schema 2 receipt 契约均保持不变。

## 从 0.23.0 升级

1. 将 Nexora 依赖更新到 `v0.23.1`。
2. 原来需要 `.row_selectable(false)` 或其他 `TableState` builder 选项的持久化表格，改用
   `persistent_crud_table_state_with`，在 `configure` 回调中保留这些选项。
