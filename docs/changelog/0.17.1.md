# Nexora 0.17.1

发布日期：2026-07-28

本版本继续处于 `0.x` beta 阶段，不进入 `1.x` 稳定通道；版本号使用标准 SemVer `0.17.1`。
本次发布修复默认桌面 Shell 侧边栏品牌区域在窄宽度下把应用名称或副标题按字符换行的问题。

## Fixed

- 默认 `SidebarHeader` 的品牌行和文本列增加宽度、溢出隐藏和单行省略约束，应用名称与副标题会保持横向单行显示，并在空间不足时截断。处理人：[@zhutao525](https://github.com/zhutao525)
- 增加 Sidebar Shell 源码契约测试，锁定默认品牌 Header 必须包含 `w_full`、`flex_1`、`overflow_hidden`、`whitespace_nowrap` 与 `truncate`，防止后续回退为逐字换行。处理人：[@zhutao525](https://github.com/zhutao525)

## Changed

- 根 workspace 版本、内部 workspace 依赖约束、CLI 安装示例和更新日志索引同步更新到 `0.17.1`。处理人：[@zhutao525](https://github.com/zhutao525)

## Issue 与 PR

- Issue：无。本版本来自 iMES Portal 本地 refactor 分支 `51bb83d4` 中验证过的通用框架修复。
- PR：无；按当前发布流程由 `codex/sidebar-brand-nowrap-v0.17.1` 分支直接提交、打 tag 并发布。

## 兼容性与破坏性变更

- 无破坏性变更。自定义 `SidebarHeader` 的应用不受影响；未自定义 Header 的应用只会获得默认品牌区的 nowrap/truncate 修复。
- 本版本不包含数据库迁移，不需要执行额外数据升级步骤。

## 升级

1. 把 Nexora tag 更新为 `v0.17.1` 并重新锁定依赖。
2. 如果应用使用默认 Sidebar Header，无需改代码即可获得品牌名称和副标题的单行截断行为。
3. 如果应用自定义了 `SidebarHeader`，请在自定义组件内部自行决定是否添加 `min_w_0`、`overflow_hidden`、`whitespace_nowrap` 和 `truncate`。
