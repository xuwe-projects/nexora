# Nexora 0.23.0

发布日期：2026-08-03

## 摘要

本版本补齐 Windows x86_64 桌面发布链路：`nexora build` 可以生成 NSIS 3 Unicode
`Setup.exe` 与自动更新 ZIP，Windows updater sidecar 可以安全解压、校验并替换更新包。
Setup.exe 只用于首次安装，自动更新清单只引用 `windows_update_zip`，不会生成或运行 MSI。

处理人：[@Jixiangup](https://github.com/Jixiangup)

关联 Issue/PR：无

## Added

- Windows target 支持 `windows_setup_exe` 与 `windows_update_zip` 两类 artifact；发布 manifest
  只把 `windows_update_zip` 写入自动更新 payload，Setup.exe 作为首装分发产物上传。— 处理人：
  [@Jixiangup](https://github.com/Jixiangup)
- Windows NSIS 打包配置支持 user/machine 安装范围、发布者、桌面快捷方式默认值、安装后启动、
  最低 Windows build、Authenticode thumbprint 与 timestamp URL。— 处理人：
  [@Jixiangup](https://github.com/Jixiangup)
- Windows updater runtime 增加 ZIP 安全解压、重复/缺失文件校验、路径逃逸拒绝、reparse point
  防护、主程序与 sidecar 签名身份校验，以及 sidecar 替换入口。— 处理人：
  [@Jixiangup](https://github.com/Jixiangup)
- 新增 `examples/updater-windows`，用于在 Windows x86_64 主机上验证 Setup.exe、更新 ZIP、
  本地 RustFS/S3 发布源和 sidecar 更新流程。— 处理人：[@Jixiangup](https://github.com/Jixiangup)

## Changed

- `nexora doctor` 和 build dependency 检查支持 Windows 主机，能发现 `rc.exe`、`makensis.exe`
  与 `signtool.exe`；NSIS 安装器脚本使用 Unicode 编码写入。— 处理人：
  [@Jixiangup](https://github.com/Jixiangup)
- build/publish 的 target 与 artifact 校验从 macOS-only 扩展为 macOS/Windows 平台分支；
  macOS `.app.zip`/DMG 行为保持不变。— 处理人：[@Jixiangup](https://github.com/Jixiangup)
- 打包示例和文档统一升级到 Nexora `v0.23.0`。— 处理人：
  [@Jixiangup](https://github.com/Jixiangup)

## Fixed

- Windows 上 release receipt 原子写入不再尝试同步目录句柄，避免 `拒绝访问` 导致构建前失败。
  — 处理人：[@Jixiangup](https://github.com/Jixiangup)
- updater bundle 配置要求 Windows 签名 thumbprint 与 publisher 成对配置，避免只校验证书或只校验
  发布者名称。— 处理人：[@Jixiangup](https://github.com/Jixiangup)

## 兼容性与破坏性变更

没有破坏性变更。macOS artifact 名称、DMG alias 与自动更新 manifest kind 保持兼容。
Windows 旧 `windows_zip` kind 在运行时仍可识别；新构建与发布产物统一写作 `windows_update_zip`。

从本版本开始，Windows 首装产物为 NSIS `*.setup.exe`，不生成 MSI。自更新流程只下载并应用
`*.windows.zip`，不会下载或运行 Setup.exe。

## 从 0.22.0 升级

1. 将全部 Nexora 依赖统一更新到 `v0.23.0` 并重新生成 lockfile。
2. Windows 应用在 `nexora.toml` 中补齐 `platforms.windows`，至少配置 ICO、`installer = "nsis"`、
   `install_scope`、`publisher` 和签名策略。
3. Windows 发布机安装 NSIS 3 Unicode、Windows SDK `rc.exe`/`signtool.exe`，并准备 Authenticode
   证书；更新私钥继续只通过文件或环境变量注入，不能提交。
4. 执行 `nexora build --app <app>`，确认 `artifact.json` 只包含 `windows_setup_exe` 与
   `windows_update_zip`，且发布清单中的 updater artifact 只引用 ZIP。
5. 执行 `nexora publish --app <app> --dry-run`，确认匿名 URL、SHA-256 和 signed `latest.json`
   校验通过后再正式发布。
