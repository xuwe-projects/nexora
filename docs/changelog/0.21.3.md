# Nexora 0.21.3

发布日期：2026-08-03

## 摘要

本补丁修复 Sidebar Footer 菜单中的“检查更新”在活动窗口事件期间重入同一窗口、导致更新
对话框未打开的问题，并为检查更新入口补充跨平台默认快捷键及菜单提示。

处理人：[@Jixiangup](https://github.com/Jixiangup)

关联 Issue/PR：无

## Fixed

- `CheckForUpdates` Action 现在把活动窗口更新延迟到当前 GPUI 窗口事件结束后执行，避免从
  Footer 菜单分发 Action 时因窗口重入而静默跳过更新对话框。— 处理人：
  [@Jixiangup](https://github.com/Jixiangup)
- `install_updater` 现在注册检查更新默认快捷键：macOS 使用 `Cmd+Shift+U`，Windows/Linux
  使用 `Ctrl+Shift+U`；Sidebar Footer 菜单同步展示当前平台快捷键。— 处理人：
  [@Jixiangup](https://github.com/Jixiangup)
- 新增菜单 Action、快捷键绑定和延迟窗口更新的回归测试。— 处理人：
  [@Jixiangup](https://github.com/Jixiangup)

## Documentation

- 在桌面 updater 文档中说明 Footer、macOS 原生菜单与快捷键共用同一个
  `CheckForUpdates` Action。— 处理人：[@Jixiangup](https://github.com/Jixiangup)

## 兼容性与破坏性变更

没有破坏性变更，也无需手工迁移。已经调用 `nexora::desktop::install_updater` 的桌面应用只需
升级全部 Nexora 依赖并重新构建，即可获得修复后的 Footer 入口和默认快捷键。未安装 updater
的应用仍不会显示检查更新入口。

## 从 0.21.2 升级

1. 将全部 Nexora 依赖统一更新到 `v0.21.3` 并重新生成 lockfile。
2. 重新构建桌面应用。
3. 在 Sidebar Footer 菜单点击“检查更新”，并分别验证菜单显示的快捷键与键盘触发行为。

本版本没有修改脚手架 Skill、宏规则或生成项目约束，下游无需同步 `.agents/skills`。

## 验证

- `cargo clippy --workspace --all-targets --all-features -- -D warnings`
- `cargo run -p nexora -- lint --workspace . --deny-warnings`
- `bash scripts/check-scaffold-consumer.sh`
- `cd docs && bun install --frozen-lockfile && bun run build`

GPUI 测试窗口不具备真实 macOS 原生窗口，无法在自动化测试中直接渲染更新对话框；发布后还需
在已打包桌面应用中执行真实点击与快捷键冒烟验证。
