# Nexora 0.40.2

发布日期：2026-08-18

本版本恢复 `gpui-component` 的原生标题栏尺度，并统一 Shell 顶部工具图标的视觉尺寸，改善
Windows 与 macOS 上标题栏偏高、图标显得拥挤的问题。

## 修复

- 工作区不再把官方 `TitleBar` 从默认 34px 强制放大到 44px；窗口控制按钮与 macOS 交通灯
  继续完全使用上游布局。

  — 处理人：[@Jixiangup](https://github.com/Jixiangup)
  — 关联 Issue/PR：无

- 前进、后退、刷新、打开页面以及标准 `ShellToolbarAction` 的可见图标统一为 16px，与 Feature
  标签图标保持一致；按钮点击区域仍为 32×32px，并保留 hover、disabled、loading 和 tooltip
  语义。侧边栏图标继续保持原有 20px 尺寸。

  — 处理人：[@Jixiangup](https://github.com/Jixiangup)
  — 关联 Issue/PR：无

- 增加工作区布局与 Shell 工具按钮回归测试，固定上游标题栏高度跟随关系、16px 工具图标和
  32×32px 点击区域。

  — 处理人：[@Jixiangup](https://github.com/Jixiangup)
  — 关联 Issue/PR：无

## 兼容性与破坏性变更

- 这是 `v0.40.1` 的向后兼容补丁，不新增或删除公开配置、路由、数据库结构或 HTTP API。
- 不提供标题栏高度自定义 API，也没有引入或维护 `gpui-component` 私有 fork。
- 无破坏性变更，无需手工迁移或回滚数据。

## 从 0.40.1 升级

1. 将所有 Nexora Git 依赖 tag 从 `v0.40.1` 更新为 `v0.40.2`。
2. 运行 `cargo update`，确认 `Cargo.lock` 中 Nexora workspace package 指向 `v0.40.2`。
3. 重新构建桌面应用；使用标准 `WorkspaceLayout` 和 `ShellToolbarAction` 的应用会自动采用新尺度。

本版本没有修改脚手架 Skill、生成项目约束或自定义宏规则，下游无需同步 `.agents/skills`。

## 验证

- `cargo fmt --all --check`
- `cargo test --workspace --all-targets`
- `cargo clippy --workspace --all-targets --all-features -- -D warnings`
- `cargo run -p cli -- lint --workspace . --deny-warnings`
- `bash scripts/check-scaffold-consumer.sh`
- `cd docs && bun install --frozen-lockfile && bun run build`

本版本不涉及 PostgreSQL、OIDC 或发布签名行为，未执行依赖这些外部环境的集成验证。
