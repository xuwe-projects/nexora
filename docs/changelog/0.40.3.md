# Nexora 0.40.3

发布日期：2026-08-18

本版本修复桌面 Shell 标题栏中的全局搜索入口无法通过鼠标稳定打开的问题。双击 Shift 快捷键、
搜索内容和标题栏空白区域拖动行为保持不变。

## 修复

- 全局搜索继续使用官方 `gpui-component::Button` 与 `Dialog`，并在按钮的左键按下事件上阻止
  继续传播，避免官方 `TitleBar` 的窗口拖拽逻辑接管点击。鼠标单击与双击 Shift 现在会进入
  同一个 `open_search` 流程。

  — 处理人：[@Jixiangup](https://github.com/Jixiangup)
  — 关联 Issue/PR：无

- 增加 Shell 回归断言，要求全局搜索按钮自身的交互区域持续隔离标题栏拖拽事件，避免只验证
  `.on_click` 存在却遗漏真实指针事件边界。

  — 处理人：[@Jixiangup](https://github.com/Jixiangup)
  — 关联 Issue/PR：无

- 修正 Sidebar 源码结构测试对 `LF` 换行的隐式依赖，使同一断言在 Windows `CRLF` 工作区中
  也能精确定位目标实现；该调整不改变 Sidebar 运行时行为。

  — 处理人：[@Jixiangup](https://github.com/Jixiangup)
  — 关联 Issue/PR：无

## 兼容性与破坏性变更

- 这是 `v0.40.2` 的向后兼容补丁，不新增或删除公开 API、配置、路由、数据库结构或 HTTP API。
- `docs/public/openapi.yaml` 的发布元数据版本同步到 `0.40.3`，接口契约本身未变更。
- 标题栏空白区域仍可拖动窗口；已注册的全局搜索快捷键、搜索 Provider 与搜索历史行为不变。
- 无破坏性变更，无需手工迁移或回滚数据。

## 从 0.40.2 升级

1. 将所有 Nexora Git 依赖 tag 从 `v0.40.2` 更新为 `v0.40.3`。
2. 运行 `cargo update`，确认 `Cargo.lock` 中 Nexora workspace package 指向 `v0.40.3`。
3. 重新构建桌面应用，并验证鼠标单击标题栏全局搜索入口与双击 Shift 都能打开搜索窗口。

本版本没有修改脚手架 Skill、生成项目约束或自定义宏规则，下游无需同步 `.agents/skills`。
