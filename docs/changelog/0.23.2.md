# Nexora 0.23.2

发布日期：2026-08-03

## 摘要

本补丁把 Settings 列布局持久化扩展到必须直接实现 gpui-component `TableDelegate` 的动态表格，
让业务无需复制 Nexora 文件 I/O 或设置合并逻辑。

处理人：[@Jixiangup](https://github.com/Jixiangup)

关联 Issue/PR：无

## Added

- 新增 `PersistentDataTableDelegate` 与 `persistent_data_table_state_with`，恢复仍存在的列顺序、
  限制后的列宽，并在原生列移动或缩放交互完成后写入应用共享 `settings.json`。— 处理人：
  [@Jixiangup](https://github.com/Jixiangup)

## Compatibility

- 0.23.0/0.23.1 的 CRUD DataTable API、Settings、多通道 release、runtime config、feed 和
  schema 2 receipt 契约保持兼容。
- 原生 delegate 的后台排序仍由自身 `perform_sort` 处理；通用后台排序继续使用
  `CrudTableDelegate` 契约。

## 从 0.23.1 升级

1. 将 Nexora 依赖更新到 `v0.23.2`。
2. 对不能使用 `CrudTableDelegate` 的表实现 `PersistentDataTableDelegate`，并用稳定 `table_id`
   调用 `persistent_data_table_state_with`。
