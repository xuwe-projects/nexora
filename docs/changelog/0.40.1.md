# Nexora 0.40.1

## 修复

- `@Jixiangup`：从 `nexora::account` 与 `nexora::server` 公开
  `CreateServiceAccountIdentity`，让宿主应用能够调用 0.40.0 新增的
  `Account::create_or_reuse_service_account`。
- 增加公共 facade 编译测试，防止服务账号创建方法再次出现“方法公开但输入类型不可达”的问题。

## 兼容性

- 这是 0.40.0 的向后兼容补丁，不包含数据库迁移、配置变更或行为变更。
- 使用服务账号宿主 API 的项目应直接升级到 `v0.40.1`；其余 0.40.0 使用方无需修改代码。

## 验证

- `cargo fmt --all -- --check`
- `cargo check --workspace --all-targets`
- `cargo test -p nexora --features desktop,server,derive`
- `cargo clippy --workspace --all-targets --all-features -- -D warnings`
- `cargo run -p cli -- lint --workspace --deny-warnings`
