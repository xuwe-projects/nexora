# Nexora 0.18.0

发布日期：2026-07-29

本版本继续处于 `0.x` beta 阶段，不进入 `1.x` 稳定通道；版本号使用标准 SemVer `0.18.0`。
本次发布把 CRUD 表格行身份和选择交互标准化为强类型受控模型，同时补齐表单字段组件、
官方 example target 和组件参考文档。

## Added

- 新增 `nexora::desktop::LabeledControl`、`LabeledControlBuilder`、`Event`、
  `LabeledControlTarget`、`FieldValue`、`NumberFieldValue` 与 `FieldValueParseError`，
  支持标签、说明、错误文本、声明式规则、类型化字段值和异步字段事件。处理人：[@Jixiangup](https://github.com/Jixiangup)
- `FormDialogState` 新增类型化字段注册能力，`FormDialog` 提交时会等待字段当前异步任务、
  执行声明式校验，并把焦点移动到首个无效字段。处理人：[@Jixiangup](https://github.com/Jixiangup)
- `FormItem` 新增 `error`、`field` 与 `full_row`，可直接复用 `LabeledControl` 字段，并让
  多列表单中的单个字段跨越整行。处理人：[@Jixiangup](https://github.com/Jixiangup)
- `CrudTableDelegate` 新增受控选择列、行复选框、表头当前已加载行批量选择事件、加载更多
  状态和空状态文案配置。处理人：[@Jixiangup](https://github.com/Jixiangup)
- 将最小桌面和服务端示例收进 `crates/nexora/examples`，作为 `desktop_basic` 与
  `server_basic` 官方 Cargo example target，并在 README 增加运行命令。处理人：[@Jixiangup](https://github.com/Jixiangup)
- 新增 `refine-implementation-spec` Skill，并同步到脚手架模板，帮助下游在实现前整理
  可交接规格。处理人：[@Jixiangup](https://github.com/Jixiangup)

## Changed

- `#[derive(nexora::CrudTableRow)]` 现在要求显式声明一个 `#[nexora(row_id)]` 字段，并由行
  类型自身提供强类型业务 ID。处理人：[@Jixiangup](https://github.com/Jixiangup)
- `CrudTableDelegate` 改为校验当前已加载行的业务 ID 唯一性，并通过
  `replace_rows`、`append_rows`、`update_rows` 管理行集合；`update_rows` 只允许修改非身份
  字段或调整当前行顺序。处理人：[@Jixiangup](https://github.com/Jixiangup)
- `TableHeaderCell` 支持通过 `element` 使用任意 GPUI 元素作为表头内容，选择列表头复选框
  复用同一对齐语义。处理人：[@Jixiangup](https://github.com/Jixiangup)
- 默认 Account 用户和角色管理页面的筛选区域改用 `LabeledControl`，保持标签、说明和控件
  密度一致。处理人：[@Jixiangup](https://github.com/Jixiangup)
- 表单对话框高度配置统一为 `max_panel_height_ratio`，短内容不再被强制撑高，只在超过
  上限时滚动内容区。处理人：[@Jixiangup](https://github.com/Jixiangup)
- 仓库规则、脚手架 Skill 和生成项目约束同步强调组件优先级、Feature 拆分、服务端组合边界
  与发布验证要求。处理人：[@Jixiangup](https://github.com/Jixiangup)

## 兼容性与破坏性变更

- 破坏性变更：`CrudTableRow` 派生结构体必须声明且只能声明一个 `#[nexora(row_id)]` 字段。
  旧的“在 `CrudTableDelegate` 上通过闭包声明 row_id”的写法不再保留。
- 破坏性变更：`CrudTableDelegate::rows_mut` 不再作为任意可变入口使用。需要替换全部数据时
  用 `replace_rows`，追加分页数据用 `append_rows`，只修改非身份字段或重排当前行时用
  `update_rows`。
- 破坏性变更：`FormDialog::panel_height_ratio` 和 `default_panel_height` 被
  `max_panel_height_ratio` 取代；默认行为改为短内容自适应、长内容按 Panel 高度上限滚动。
- 本版本没有新增数据库迁移、HTTP 路由或服务端配置项；服务端部署不需要执行数据升级。

## 升级

1. 把 Nexora tag 更新为 `v0.18.0` 并重新锁定依赖。
2. 为所有 `#[derive(nexora::CrudTableRow)]` 的结构体补充 `#[nexora(row_id)]`。如果行 ID 不
   应显示在表格里，可以写成 `#[nexora(row_id, skip)]`。
3. 移除旧的 `CrudTableDelegate::row_id(...)` 调用，把业务 ID 保留在行类型中。
4. 把旧的 `rows_mut()` 更新为 `replace_rows`、`append_rows` 或 `update_rows`；不要在
   `update_rows` 中增加、删除或修改业务 ID。
5. 需要行选择时，使用 `CrudTableSelection::new(selected_ids, on_select_row,
   on_select_loaded_rows)`，在事件回调里更新业务 selected IDs，再调用 `set_selected_ids`
   回写渲染快照。
6. 把 `FormDialog::panel_height_ratio(...)` 或 `default_panel_height()` 调用迁移为
   `max_panel_height_ratio(...)`，或直接使用默认值。
7. 同步新脚手架中的 `.agents/skills`，尤其是新增的 `refine-implementation-spec` 以及更新后的
   GPUI、组件选择、Rust 和服务端规则。
8. 如需官方示例，使用 `cargo run -p nexora --no-default-features --features desktop,derive
   --example desktop_basic` 或 `cargo run -p nexora --no-default-features --features server
   --example server_basic`。
