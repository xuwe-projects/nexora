# Nexora 0.17.0

发布日期：2026-07-28

本版本继续处于 `0.x` beta 阶段，不进入 `1.x` 稳定通道；版本号使用标准 SemVer `0.17.0`。
本次发布新增桌面 Shell 主面板标题栏的应用级动作扩展点，便于宿主应用把稳定入口放入所有业务页面的
`PanelHeader` 右侧。

## Added

- 新增 `PanelHeaderAction` 与 `install_panel_header_actions` 公开 API，宿主应用可在启动阶段安装一组 `Fn(&mut App) -> impl IntoElement` 动作，框架会将其渲染到业务页面 `PanelHeader` 右侧，并位于内置的当前标签页置顶按钮之前。处理人：[@zhutao525](https://github.com/zhutao525)
- 在 `nexora::desktop` facade 与 `nexora` desktop feature 根导出中同步暴露标题栏动作 API，应用无需依赖内部 `application` 模块。处理人：[@zhutao525](https://github.com/zhutao525)

## Changed

- 根 workspace 版本、内部 workspace 依赖约束、CLI 安装示例和更新日志索引同步更新到 `0.17.0`。处理人：[@zhutao525](https://github.com/zhutao525)

## Issue 与 PR

- Issue：无。本版本来自 iMES 宿主应用对通用桌面框架标题栏入口扩展点的需求。
- PR：无；按当前发布流程由 `codex/panel-header-actions-v0.17.0` 分支直接提交、打 tag 并发布。

## 兼容性与破坏性变更

- 无破坏性变更。旧应用无需安装标题栏动作即可保持原有 Shell 行为。
- 新增公开 API 属于向后兼容功能增加；根据 Nexora 当前 `0.x` 版本策略递增 minor，因此从 `0.16.0` 升级到 `0.17.0`。

## 升级

1. 把 Nexora tag 更新为 `v0.17.0` 并重新锁定依赖。
2. 需要在所有业务页面标题栏右侧放置应用级入口时，在桌面应用启动初始化阶段构造 `PanelHeaderAction` 列表，并调用 `install_panel_header_actions(actions, cx)`。
3. 后一次 `install_panel_header_actions` 会替换前一次列表；传入空列表可清空已安装动作。
4. 标题栏动作的渲染闭包只应读取应用状态并构造元素；导航、弹窗或业务操作应放在元素事件回调中。
5. 本版本不包含数据库迁移，不需要执行额外数据升级步骤。
